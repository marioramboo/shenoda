## 2. Database & ORM Layer (`/prisma`)

This directory manages the PostgreSQL relational database schema, database migrations, and database seed datasets.

### Files & Subdirectories:
- **`prisma/schema.prisma`**:
  The central relational schema definition containing 20+ models and enums:
  - **Tenancy & Scoping**: `Organization`, `Sector`, `Stage`, `Class`.
  - **Identity & Access Control**: `User`, `Role`, `RolePermissionRule`, `UserStageScope`, `UserSectorScope`.
  - **Member Records**: `Member`, `ParentContact`, `MemberAttendance`.
  - **Servant Tracking**: `ServantProfile`, `ServantAttendance`, `ServantEvaluation`.
  - **Pastoral & Spiritual Care**: `SpiritualLifeLog` (strict privacy firewall), `PastoralNote`.
  - **Curriculum & Year Plan**: `YearPlan`, `CalendarEvent`, `EventVolunteer`, `EventAttendanceConfirmation`, `ServantPost`.
  - **Curriculum Preparation**: `LessonPreparation` (preparation authoring, scripture references, review lifecycle).
  - **Communications**: `Announcement`, `Poll`, `PollOption`, `PollVote`, `Notification`, `AuditLog`.
- **`prisma/seed.ts`**:
  Initial system seeder. Sets up standard hierarchy roles (`GENERAL_SECRETARY`, `SECTOR_SECRETARY`, `STAGE_SECRETARY`, `CLASS_SECRETARY`, `SERVANT`, `PRIEST`), basic church sectors, stages, and an initial General Secretary account.
- **`prisma/seed-demo-showcase.ts`**:
  Comprehensive demo dataset reflecting a real church ministry scenario (Preparatory Boys stage: إعدادي بنين). Seeds year plans, service meetings, curriculum lessons, servant preparations, and attendance.
- **`prisma/seed-stress.ts`**:
  High-volume stress test dataset used to benchmark database query latency, attendance indexing, and reporting pipelines.
- **`prisma/migrations/`**:
  Directory containing historical timestamped SQL migration scripts generated by Prisma Migrate.

## 3. Shared Library Package (`/packages/shared`)

Houses business rules, constants, enums, utility functions, and permission evaluation logic shared between the Node.js API backend and Next.js frontend.

### Subdirectories & Files:
- **`packages/shared/src/index.ts`**: Main export barrel exposing constants, types, permissions, and utils.
- **`packages/shared/src/constants/`**:
  - `roles.ts`: Defines `RoleKey` enum, tier rankings (Tier 1 General Secretary down to Tier 5 Servant), Arabic and English titles.
  - `stages.ts`: Stage types (Kindergarten, Primary, Preparatory, Secondary, University, Graduates).
  - `sessions.ts`: Attendance session types (`MASS`, `SERVICE_MEETING`, `LESSON_PREPARATION`, `PASTORAL_VISITATION`, etc.).
  - `prepAndSpiritual.ts`: Preparation statuses (`DRAFT`, `SUBMITTED`, `REVIEWED`) and spiritual sacrament types.
  - `yearPlanAndCalendar.ts`: Event categories (`SERVICE_MEETING`, `SPIRITUAL_LESSON`, `CONFERENCE_RETREAT`, `TRIP_OR_OUTING`), color badges, and volunteer capacities.
  - `announcementsAndPolls.ts`: Notification types and poll visibility configurations.
- **`packages/shared/src/permissions/`**:
  - `matrix.ts`: The granular permission matrix mapping actions (`MANAGE_YEAR_PLAN`, `TRANSFER_SUSPEND_SERVANT`, `SUBMIT_EVALUATION`, etc.) to minimum role tiers.
  - `evaluator.ts`: Logic verifying whether a given user holds the required level and scope to execute an operation.
  - `types.ts`: TypeScript interfaces for permission evaluation and action authorization.
- **`packages/shared/src/utils/`**:
  - `copticDate.ts`: Converts Gregorian dates to the traditional Coptic liturgical calendar (months: Tout, Baba, Hator, Kiahk, etc.).
  - `phone.ts`: Egyptian phone number normalizer and validator supporting Vodafone, Orange, Etisalat, and WE formats (`+201...`).
- **`packages/shared/src/types/`**:
  - `common.ts`: Standard API response envelopes (`ApiResponse<T>`), pagination structures, and error payloads.
- **`packages/shared/tests/`**:
  - `permissions.test.ts`: Unit test suite verifying hierarchical role authorization and scope containment.
  - `phone.test.ts`: Tests asserting valid vs. invalid phone number normalization.

## 4. API Backend Application (`/apps/api`)

An Express.js REST application written in TypeScript providing security, validation, database access, background cron tasks, and business workflows.

### Directory Structure & Inventory:

#### Root Files:
- **`src/server.ts`**: Starts HTTP listener, registers graceful shutdown handlers (`SIGTERM`, `SIGINT`), and connects to PostgreSQL and Redis.
- **`src/app.ts`**: Express application factory mounting CORS, Helmet, JSON body parser, request logging, and all API router modules under `/api/v1/` and `/api/`.

#### Middleware (`src/middleware/`):
- `auth.ts`: Extracts and verifies JWT bearer tokens, attaches authenticated `req.user` context (user ID, role code, role level, stage/sector scopes).
- `authorize.ts`: Guard enforcing minimum role levels and permission rules per endpoint.
- `idempotency.ts`: Intermittent connectivity protection. Uses Redis and `X-Idempotency-Key` headers to cache mutating operations (prevents duplicate attendance marking in church basements with weak reception).
- `rateLimiter.ts`: IP and user token rate-limiting to prevent brute force and DDoS attacks.

#### Controllers (`src/controllers/`):
- `auth.controller.ts`: Authenticates servants, generates JWT access and refresh tokens, handles password recovery and reset.
- `account.controller.ts`: Manages servant profiles, activation, and role assignments. Enforces General Secretary-only restrictions for servant transfer or suspension.
- `yearPlan.controller.ts`: Annual plan creation and publication. Handles adding, updating, and deleting calendar events. **Restricts adding, editing, or deleting servant meetings (`SERVICE_MEETING`, `SECRETARIES_COUNCIL`) strictly to the General Secretary**.
- `calendar.controller.ts`: Lists church calendar events, handles servant volunteer registrations with capacity limits, and bridges event confirmations to attendance records.
- `preparation.controller.ts`: Full lesson preparation workflow: servant submission, reference checks, supervisor review (approve/reject), and lesson inspection (identifying who prepared vs. unprepared).
- `member.controller.ts`: Member CRUD, pastoral notes, profile editing, and scope filtering by class, stage, or sector.
- `memberAttendance.controller.ts`: Attendance marking for church members in classes and masses.
- `servantAttendance.controller.ts`: Attendance tracking for servants across sessions (Masses, Service Meetings, Preparations, Visitations).
- `spiritualLife.controller.ts`: Confidential spiritual journal (sacraments, confessions, Bible readings). **Protected by an absolute privacy firewall** (even General Secretaries cannot view another servant's entries).
- `announcement.controller.ts`: Stage and church-wide notices with downward-only hierarchy targeting.
- `poll.controller.ts`: Church polls, vote submissions, anonymous and identified tallying.
- `notification.controller.ts`: In-app notification delivery and read status management.
- `analytics.controller.ts`: Stage and sector analytics endpoints supplying aggregated metrics without exposing private spiritual records.
- `dashboard.controller.ts`: Personal servant dashboard aggregating pending tasks, assigned students, and missing follow-ups.
- `report.controller.ts`: Generates structured Excel spreadsheets and PDF attendance sheets.
- `note.controller.ts`: Pastoral notes and follow-up observations on students.
- `servantPost.controller.ts`: Stage-isolated discussion and coordination posts for servants.
- `alert.controller.ts`: Dropout alerts and chronic absence detection.

#### Routes (`src/routes/`):
- Maps REST endpoints to corresponding controller functions with authentication and authorization middleware applied.
  - Files: `auth.routes.ts`, `account.routes.ts`, `yearPlan.routes.ts`, `calendar.routes.ts`, `preparation.routes.ts`, `member.routes.ts`, `attendance.routes.ts`, `spiritualLife.routes.ts`, `announcement.routes.ts`, `poll.routes.ts`, `notification.routes.ts`, `analytics.routes.ts`, `dashboard.routes.ts`, `report.routes.ts`, `note.routes.ts`, `permissions.routes.ts`, `health.routes.ts`.

#### Services (`src/services/`):
- `token.service.ts`: Signs and verifies HMAC/RSA JWT access and refresh tokens.
- `hash.service.ts`: Bcrypt password hashing and validation.
- `scopeResolver.service.ts`: Resolves stage and sector relationships for hierarchical queries.
- `memberAccess.service.ts`: Filters database queries according to servant stage and class assignments.
- `evaluationHierarchy.service.ts`: Validates that evaluations strictly follow top-down hierarchy (supervisors evaluate subordinates; self-evaluation is rejected).
- `eventAttendanceSync.service.ts`: Synchronizes event check-ins directly into attendance tables.
- `absenceDetector.service.ts`: Detects consecutive absences and generates proactive alerts for servants.
- `announcementAudience.service.ts`: Enforces downward-addressing rules (prohibits subordinates addressing superiors church-wide).
- `attendanceAnalytics.service.ts`: Computes attendance percentages, trends, and retention rates.
- `bulkImport.service.ts`: Parses and validates batch Excel member uploads.
- `volunteer.service.ts`: Manages event volunteer capacities and concurrency locks.
- `sensitiveLogger.service.ts`: Sanitizes logs to prevent sensitive PII or spiritual records from writing to standard output.
- `spiritualLife.service.ts`: Encapsulates owner-only spiritual access rules.
- `storage.service.ts`: File storage abstraction for lesson attachments and photos.
- `notificationQueue.service.ts`: Asynchronous delivery queue for notifications.
- `analytics/dashboardAnalytics.service.ts`: Database query aggregation for high-level dashboards.
- `analytics/securityAssert.ts`: Runtime security assertion verifying that no spiritual models are ever leaked into analytics payloads.
- `reports/excelGenerator.service.ts`: Produces multi-tab `.xlsx` workbooks with styled headers and Arabic formatting.
- `reports/pdfGenerator.service.ts`: Produces printable PDF rosters and attendance sheets.

#### Config & Jobs (`src/config/`, `src/jobs/`):
- `src/config/env.ts`: Validates and parses environment variables.
- `src/config/prisma.ts`: Singleton Prisma client instance.
- `src/config/redis.ts`: Redis client configuration for caching and idempotency locks.
- `src/jobs/reminderCron.ts`: Background cron jobs sending reminders for upcoming meetings and flagging follow-up lapses.

#### Test Suite (`apps/api/tests/`):
- Complete automated end-to-end integration test suite (118 tests):
  - `authAndAccount.test.ts`: Authentication, refresh tokens, role security.
  - `yearPlanAndCalendar.test.ts`: Year plan authoring, volunteer capacity, calendar events, **and General Secretary meeting permissions**.
  - `servantSelfService.test.ts`: Lesson preparation, inspection, and the spiritual privacy firewall.
  - `attendanceAndFollowUp.test.ts`: Attendance records, session types, and absence alerts.
  - `memberRecords.test.ts`: Member scoping, CRUD, and pastoral notes.
  - `announcementsAndPolls.test.ts`: Announcements, downward communication restrictions, and voting.
  - `analyticsAndReports.test.ts`: Dashboard aggregation, PDF and Excel exports.
  - `scopeIsolation.test.ts`: Cross-stage and cross-sector isolation penetration tests.
  - `securitySweep.test.ts`: Zero public registration audit, spiritual firewall audit, and idempotency tests.
  - `evaluationHierarchy.test.ts`: Evaluation downward flow enforcement.
  - `helpers/mockDb.ts`: In-memory database simulation for isolated and fast integration testing.

## 5. Web Frontend Application (`/apps/web`)

A modern, responsive Next.js 14 web application built with Tailwind CSS, Lucide icons, full Arabic RTL support, and role-based views.

### Directory Structure & Inventory:

#### Application Routes (`apps/web/app/`):
- **`app/layout.tsx`**: Root layout wrapping the app with `AuthProvider`, RTL styling, Cairo font, and toast notifications.
- **`app/page.tsx`**: Landing and routing hub directing servants to their active service dashboard.
- **`app/globals.css`**: Tailwind directives, custom church color tokens (`brand-primary`, `brand-accent`, `bg-surface`, `bg-muted`), and typography classes.
- **`app/(auth)/login/page.tsx`**: Secure login portal with phone number normalization, password masking, and role redirect.
- **`app/(auth)/forgot-password/page.tsx`**: Password reset request workflow.
- **`app/dashboard/page.tsx`**: Main servant dashboard displaying quick actions, attendance alerts, unreviewed preparations, and stage metrics.
- **`app/members/page.tsx` & `app/members/[id]/page.tsx`**: Student and member roster with search, filtering, detailed profile, pastoral history, and contact shortcuts.
- **`app/attendance/page.tsx`**: Modern attendance-taking interface for weekly classes, Mass attendance, and visitation logs.
- **`app/plan/page.tsx`**:
  The central **Stage Plan & Ministry Management** page divided into 3 tabs:
  1. **اجتماع خدام (Servants' Meeting)**:
     - Allows viewing regular meeting dates and agendas.
     - **Permission Rule**: Strictly allows only the General Secretary (`الأمين العام`) to add, edit, or delete meetings. Stage Secretaries (`أمين الخدمة`) have clean, read-only visibility.
  2. **تدبير الخدمة (Service Activities)**: General church feasts, trips, spiritual retreats, and volunteer coordination.
  3. **تحضير الدروس (Lesson Preparation & Inspection)**: Curriculum lessons, compulsory ecclesiastical references, servant preparation submissions, and supervisor inspection of prepared vs. unprepared servants.
- **`app/calendar/page.tsx`**: Unified liturgical and service calendar with monthly/weekly views and volunteer sign-ups.
- **`app/announcements/page.tsx`**: Interactive announcements feed and active church polls with voting.
- **`app/analytics/page.tsx`**: Visual graphs, attendance percentages, dropout rates, and export triggers for supervisors.
- **`app/preparations/page.tsx`**: Dedicated servant interface for authoring, editing, and submitting lesson preparation reflections.
- **`app/profile/page.tsx`**: Servant profile settings, contact information, and personal preferences.
- **`app/year-plan/page.tsx`**: High-level annual plan overview.

#### Components (`apps/web/components/`):
- **`ui/`**: Base UI library (Tailwind-styled buttons, text inputs, badges, chips, modals, stat cards, dropdowns).
- **`layout/`**: Header, navigation sidebar, mobile bottom navigation bar (`TabBar`), breadcrumbs.
- **`auth/`**: `ProtectedRoute.tsx` (route guard checking authentication and minimum role level before rendering).
- **`attendance/`**: Fast attendance checklists, status counters (Present, Absent, Excused), and mass logs.
- **`calendar/`**: Calendar event cards, volunteer badges, and date pickers.
- **`members/`**: Member card, search input, stage filter tabs, and detail cards.
- **`polls/`**: Interactive poll cards, radio vote submissions, and live percentage bars.
- **`reports/`**: Export buttons for Excel and PDF generation.
- **`spiritual/`**: Confidential spiritual tracker components.
- **`providers/`**: Context and client state wrappers.

#### Supporting Modules:
- **`context/AuthContext.tsx`**: Client authentication state manager storing current user, JWT tokens, active role tier, and stage scopes in local storage and memory.
- **`i18n/`**: Bilingual dictionary with Arabic (`ar.ts`) and English (`en.ts`) translations tailored to Coptic Orthodox terminology.
- **`lib/api.ts`**: Axios instance pre-configured with base URL, automatic authorization token injection, and unified error handling.
- **`lib/utils.ts`**: Style merging utility combining `clsx` and `tailwind-merge`.
